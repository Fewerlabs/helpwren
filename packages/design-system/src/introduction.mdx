# Helpwren design system

Calm interface, hand-drawn character: warm paper, ink lines, generous space, outlines instead of
shadows.

This Storybook documents the tokens, the base and shared components, and the wren illustrations.
Components are added phase by phase; see `docs/design-system.md` in the repository for when to use
each one.

Every story is also run as a test, including an accessibility check.
