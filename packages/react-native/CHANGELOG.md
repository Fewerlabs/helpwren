# @helpwren/react-native

## 0.1.0

### Minor Changes

- First release. `SupportScreen` shows an install's chat in a web view, signs the user in with
  their token, passes the screen they are on, and reports the unread count.
- `getUnreadCount` for a badge outside the chat, and `registerSupportDevice`,
  `unregisterSupportDevice` and `supportConversationId` for push notifications through Expo or
  Firebase.
- `@helpwren/react-native/bridge`: the message helpers on their own, for a custom screen.

### Patch Changes

- Updated dependencies
  - helpwren@0.1.0
