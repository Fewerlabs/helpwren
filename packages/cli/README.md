# @helpwren/cli

> **Status: stub.** Nothing is implemented yet. This package exists so the workspace layout,
> naming and tooling are settled before product work starts.

The one-command Helpwren installer and upgrader.

## What it will contain

- `install`: asks for the database URL, service key and app address, applies migrations and
  deploys the app.
- `upgrade`: updates the app and applies new migrations, listing anything that needs attention.

See the [build plan](../../docs/helpwren-build-plan.md), sections 4.10 and 4.15.
