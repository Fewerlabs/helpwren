# Landing page: check against the brief

Every requirement in `docs/helpwren-landing-page-prompt.md`, one row each, checked in a browser
on the production build (`pnpm --filter @helpwren/site build && … start`). Screenshots are in
[`screenshots/`](screenshots/): `seq-1280-light-NN` is a desktop sequence scrolled with the wheel
from top (00) to bottom (11), `seq-1280-dark-NN` the same in dark, `seq-375-*` a phone,
`perched-{light,dark}-<perch>` the wren just after it lands at each perch, and `no-js-*` and
`reduced-motion-*` full pages.

Where a row says **Done, changed**, the brief's words could not be followed literally without
saying something untrue about the product, or the owner asked for something else later; the row
says which.
